# MEND UK Branding & Themes

## Brand
- App name: **MEND UK**
- Positioning: **Repairs. Trust. Homes.**
- Visual mark: UK-home silhouette + repair tool motif + Union Jack badge.
- Primary app background: clean white with a very subtle transparent Union Jack watermark.
- Dark mode: deep blue-green surface with the same low-opacity UK watermark.

## Appearance
Settings now supports:
- Day mode
- Dark mode
- System default

The preference is persisted locally with AsyncStorage and the native system colour scheme is updated when the user chooses Day/Dark. Payment, auth, navigation and shared UI components remain compatible with the selected appearance.
